# Atlas User Workflow

Atlas is the user's health operating system.

ChatGPT is the user's coach.

Atlas never interrupts coaching.

Atlas preserves the outcome of coaching.

---

# Home Screen

When Atlas launches, the user is presented with three primary actions.

## 1. View Dashboard

Review current health status, historical observations, trends, and progress toward long-term goals.

---

## 2. Import Observation from ChatGPT

Import a finalized Atlas Observation created during a ChatGPT coaching conversation.

Importing an observation updates:

- Observation History
- Dashboard
- Trend Analysis

Historical observations are never modified.

---

## 3. Export History for ChatGPT

Generate an Atlas History package for longitudinal coaching and analysis in ChatGPT.

The exported history is read-only.

It exists to provide ChatGPT with historical context for deeper analysis.

---

# Weekly Workflow

The weekly review begins in ChatGPT.

The coaching conversation remains natural and conversational.

The user may ask follow-up questions, discuss context, explore alternatives, and refine recommendations before finalizing the week's assessment.

Atlas does not participate in the coaching conversation.

When the user is satisfied, they ask ChatGPT to:

**"Finalize this week's Atlas Observation."**

ChatGPT generates a finalized Atlas Observation.

The user then opens Atlas and selects:

**Import Observation from ChatGPT**

Atlas validates the observation, stores it as an immutable historical record, and updates the dashboard.

---

# Longitudinal Review Workflow

Longitudinal reviews are initiated only when the user requests a deeper analysis.

The user opens Atlas and selects:

**Export History for ChatGPT**

Atlas generates an Atlas History package containing the user's historical observations.

The user uploads the history package to ChatGPT.

ChatGPT combines:

- Atlas History
- Current Dashboard
- Current Conversation
- User Questions

to perform longitudinal analysis.

Longitudinal reviews may include:

- Goal progress over time
- Training trends
- Nutrition trends
- Recovery trends
- DEXA comparisons
- Laboratory comparisons
- Strategic recommendations

Atlas stores historical observations.

ChatGPT performs longitudinal reasoning.
