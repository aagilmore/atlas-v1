# Atlas Dashboard v1.0 Specification

## Purpose

The Atlas Dashboard is the primary output of Atlas.

It provides a concise executive summary of health each week.

The dashboard layout is frozen for Atlas v1.

Changes require explicit product approval.

---

## Sections

1. Weekly Snapshot Header
2. Strategic Scorecard
3. Weekly Execution Scorecard
4. Atlas Weekly Brief
5. Pillar Status
6. Upcoming Events
7. Footer
